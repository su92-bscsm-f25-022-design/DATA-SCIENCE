# Assignment No. 2 — Data Cleaning and Preprocessing

Dataset: Students Performance in Exams  
Kaggle source: https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

## How to run
1. Open the `.ipynb` notebook in Google Colab.
2. Download `StudentsPerformance.csv` from the Kaggle dataset page.
3. Run the notebook cells from top to bottom.
4. Upload the CSV when prompted.
5. Review the outputs and save the generated `students_performance_cleaned.csv`.
6. Before submission, add any class-specific requirements and make sure you understand each step.

The notebook documents dataset inspection, missing values, duplicates, standardization, type validation, outlier review, variable types, feature engineering, encoding, scaling, train/test split, and leakage prevention.
